# リアルタイムチャット機能 テスト仕様書 (`05_test_spec.md`)

本ドキュメントは、要件定義書（`02_requirements.md`）、設計書（`03_design.md`）、および実装計画書（`04_implementation.md`）に基づき、リアルタイムチャット機能（`/chat`）の品質・安全性・複数インスタンス整合性および既存機能への非干渉を検証するためのテスト仕様書である。

* **文字数基準（設計確定値）**: ユーザー名は前後空白除去後 **1〜20文字**、コメントは前後空白除去後 **1〜500文字**（いずれも Unicode コードポイント数基準）。
* **定員基準（設計確定値）**: 1ルーム（`default`）あたり最大 **5接続** まで。
