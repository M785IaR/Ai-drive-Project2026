## 2. 画面設計（DES-V2-01）

* **対応REQ**: REQ-V2-01, REQ-V2-02, REQ-V2-05
* **入口URL**: `/ai/v2/`（`public/ai/v2/index.html` の静的配信、または `/ai/v2` から `index.html` を返却）

### 2.1 画面レイアウトとUI要素
V1（`public/ai/index.html`）の静的HTML＋CSS＋クライアントJS構成に合わせ、`/ai/v2/` に以下の領域を配置する。

1. **ヘッダー・ナビゲーション領域**:
   * アプリタイトル（「AI質問アシスタント V2」）、V1画面（`/ai`）およびTOP画面（`/`）への戻りリンク。
2. **新規会話作成領域**:
   * 会話名入力欄（`<input type="text">`、最大50 Unicodeコードポイント案内）
   * 「新しい会話を作成」ボタン（`<button type="submit">`）
3. **会話一覧領域（サイドバーまたは上部リスト）**:
   * 作成済み会話の一覧（新しい順）。各項目に会話名（`textContent` で描画）と選択状態（`aria-current="true"` またはアクティブクラス）を表示。
   * 0件時はエラーにせず「会話はまだありません。新しい会話を作成してください。」と表示。
4. **選択中会話の履歴表示領域**:
   * 現在選択中の会話タイトル表示欄。
   * 選択中の会話に属する**最新20往復を古い順（上から下へ時系列順）**に表示。
   * 各往復カードは「質問（あなた）」「回答（AI）」「作成日時」をすべて `textContent` のみで描画し、`innerHTML` は使用しない。
   * 会話未選択時は「左の一覧から会話を選択するか、新しい会話を作成してください。」、履歴0件の会話選択時は「この会話の履歴はまだありません。」と正常表示する。
5. **質問送信フォーム領域**:
   * 質問入力欄（`<textarea>`、前後空白を除き1〜2,000 Unicodeコードポイント）
   * 「質問を送信する」ボタン（会話未選択時は `disabled`）
   * 通信中インジケーター（「AIが回答を作成中です...」）およびエラーメッセージ表示領域（`role="alert"`）

### 2.2 クライアント状態管理・通信・復帰制御
* **初期表示・再読み込み時の挙動**:
  * ページ読み込み時に `GET /api/ai/v2/conversations` を実行して会話一覧を取得する。
  * URLクエリ（例：`?conversationId=12`）またはクライアント保持IDが一覧に存在すれば自動選択し、`GET /api/ai/v2/conversations/:id/turns` で履歴を再取得して会話を再開する。該当がなければ先頭の会話を選択するか未選択状態とする。
* **重複操作の防止**:
  * クライアント状態フラグ（`isBusy`）およびフォーム要素の `disabled` / `aria-busy="true"` により、会話作成・履歴取得・質問送信の通信中は入力欄と送信ボタンを無効化し、連打による多重リクエストを抑止する。
* **タイムアウトと失敗時復帰**:
  * `fetch` には `AbortController` によるタイムアウト（質問送信は45秒、一覧・履歴取得は15秒）を設定し、ループによる自動再送は行わない。
  * 失敗時は入力欄（会話名・質問文）の文字列を消去せず保持し、`finally` ブロックで必ず `isBusy = false` と `disabled` 解除を実行して再操作可能な状態に戻す。

## 3. API設計（DES-V2-02）

* **対応REQ**: REQ-V2-01, REQ-V2-02, REQ-V2-05
* **ベースパス**: `/api/ai/v2`
* **共通ミドルウェア順序**:
  1. V2公開停止チェックミドルウェア（停止時はボディ解析前に即座に `503` を返却）
  2. V2専用 JSON ボディパーサー（`express.json({ limit: '16kb' })`）※16 KiB超過時は `413` / `400` 固定JSONエラーを返却

### 3.1 エンドポイント一覧

| メソッド | URL | 役割 | 成功ステータス |
| :--- | :--- | :--- | :--- |
| `GET` | `/api/ai/v2/conversations` | 会話一覧の取得（最新順） | `200 OK` |
| `POST` | `/api/ai/v2/conversations` | 新規会話の作成 | `201 Created` |
| `GET` | `/api/ai/v2/conversations/:id/turns` | 指定会話の履歴取得（最新20往復・古い順） | `200 OK` |
| `POST` | `/api/ai/v2/conversations/:id/turns` | 指定会話への質問送信・文脈付きAI応答取得・1往復保存 | `201 Created` |

### 3.2 各APIの入出力仕様

#### (1) `GET /api/ai/v2/conversations`
* **入力**: なし
* **応答 (`200`)**:

    "items": [
      { "id": 12, "title": "旅行計画の相談", "createdAt": "2026-11-25T05:00:00.000Z" }
    ]
  }
